sequenceDiagram
    autonumber
    actor User
    participant View as React UI (Layout/Form)
    participant API as API Layer (api.ts)
    participant Server as Backend / DB
    participant AI as AI Summarizer Service

    %% Step 1: Candidate Creation
    User->>View: Fills form & clicks "Add Candidate"
    View->>API: createCandidate(payload)
    activate API
    API->>Server: POST /api/candidates
    activate Server
    Server-->>API: 201 Created { id: "c123", ...candidateData }
    deactivate Server
    API-->>View: Candidate Created Success
    deactivate API

    %% Step 2: Trigger AI Summary Generation
    View->>View: Update UI & trigger summary request
    View->>API: generateCandidateSummary("c123")
    activate API
    API->>Server: POST /api/candidates/c123/summarize
    activate Server
    
    %% Step 3: Backend Processing & AI Call
    Server->>Server: Fetch candidate details & history
    Server->>AI: Clean candidate data before\n sending request along with prompt
    activate AI
    AI-->>Server: Return structured text summary
    deactivate AI

    Server-->>API: 200 OK { summary: "..." }
    deactivate Server

    %% Step 4: UI Render
    API-->>View: Return summary payload
    deactivate API
    View->>User: Render candidate entry & AI summary card
